# Paper 目录准入

## 用途

这里承载从正式研究结论提升出的论文文本、图表入口和投稿材料。

内容必须能够追溯到 `docs/ideas/` 中的主张和 `experiments/` 中的正式证据。

## 准入

- 只放论文直接使用的文本、表格定义、图表入口和投稿材料。
- 图表和数字引用正式 Experiment；方法主张引用 Idea 或 Protocol。

## 禁止

- 不放研究讨论、临时图片、原始实验结果或 Codex 过程总结。
- 不在本目录产生新的实验结论；结论先写入 Experiment。

## 生命周期

论文材料随已确认的研究结论更新；投稿版本可由 Git 保存，不创建“最终版”副本。
