# References 目录准入

## 用途

这里只登记项目实际使用的论文、数据集、标准和外部实现，以及它们对当前研究的简短
作用。优先保存链接、版本和必要引用信息，不复制可以从原始来源重新获得的大文件。

没有影响研究假设、实现或实验设计的资料，不因为“以后可能有用”而加入。

## 准入

- 记录论文、数据集、标准和外部实现的稳定来源、版本、许可证和实际用途。
- 只保留足以复现引用的短说明；大文件留在原始来源或明确的外部依赖中。

## 禁止

- 不把待读清单、收藏夹或无研究作用的资料堆积在这里。
- 不用本目录替代 `reproductions/` 的来源与适配记录。

## 生命周期

资料在被 Idea、Protocol、代码或 Experiment 实际引用后进入目录；用途消失时可以删除条目，
但仍被正式证据引用的来源必须保留。
